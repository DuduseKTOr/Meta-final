Por tipo de turno
🌙 1 turno (meio período)

Melhor escolha: 18h às 23h (5h online). Você captura o pico inteiro + parte do segundo. R$ 250-350 num dia útil.

  1. Começa em Esplanada / SCN às 17h45
  2. Migra pra Asa Sul comercial depois das 19h
  3. Termina em Setor Hoteleiro / Pontão depois das 21h
  4. Evita manhã (1 turno rende menos) e tarde fraca (queima bateria sem ganho)
☀️🌙 2 turnos (integral)

~10h online com 2 pausas estratégicas. Pico da noite é o bloco mais importante.

  1. 06h30-09h30 (3h): Aeroporto → Plano Piloto. Volume alto.
  2. 09h30-11h30: pausa. Almoço cedo, recarrega.
  3. 11h30-13h30 (2h): almoço. Foca W3 / comercial.
  4. 13h30-16h: pausa. Hora morta — descanso, manutenção, etc.
  5. 17h-22h (5h): PICO. Bloco mais importante do dia.

📚 Tutorial · Configurar Drive

O Google exige que cada app tenha sua própria credencial. Configure uma vez, use pra sempre. Leva ~10 minutos.

1. Criar projeto no Google Cloud

  1. Acesse: console.cloud.google.com
  2. Faça login com a conta Google onde quer salvar os backups
  3. No topo, clique no seletor de projeto → NOVO PROJETO
  4. Nome: Motorista Backup → criar

2. Habilitar Drive API

  1. Menu lateral (☰): APIs e serviços → Biblioteca
  2. Busque Google Drive API → ATIVAR

3. Tela de consentimento

  1. Menu: APIs e serviços → Tela de consentimento OAuth
  2. Tipo: Externo → CRIAR
  3. Nome do app: Motorista Backup · email de suporte: seu email
  4. Salvar e continuar (pode pular as próximas)
  5. Em Usuários teste: clique ADD USERS → adicione seu próprio email Google → SALVAR

4. Criar credencial OAuth Client ID

  1. Menu: APIs e serviços → Credenciais
  2. Topo: + CRIAR CREDENCIAL → ID do cliente OAuth
  3. Tipo: Aplicativo da Web · Nome: Motorista App
  4. Em Origens JavaScript autorizadas, cole:
    https://SEUUSUARIO.github.io
    Só o domínio, sem o /motorista/.
  5. CRIAR → copie o Client ID

5. Colar no app

  1. Feche este tutorial → ⚙️ Configurar → cole o Client ID → salvar
  2. Vai abrir popup do Google → escolha sua conta → autorize
  3. ⚠️ Se aparecer "Google ainda não verificou": clique Avançado → Continuar
🔒 Privacidade: O app só acessa arquivos que ele próprio cria no seu Drive (escopo drive.file). Não vê seus outros arquivos.
