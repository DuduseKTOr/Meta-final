# Cockpit Motorista 2026

PWA pra motoristas de app (Uber/99/inDrive) — controle de faturamento, custos e metas.

## Funcionalidades

- 📊 Painel com meta mensal/anual editável e progresso visual
- 📅 Calendário 2026 com lançamento por plataforma e turno
- 📈 Gráficos diário/semanal/mensal/comparativo plataformas
- 🔌 Recarga elétrica (kWh, R$, R$/km)
- 🔧 Manutenção (revisão, pneus, freios, etc) com alerta automático
- 💸 Despesas pessoais com categorias e despesas recorrentes
- 🎤 Comando de voz em português
- 🧮 Calculadoras de lucro, recarga e tempo
- 🇧🇷 Feriados nacionais e do DF
- ☁️ Backup automático no Google Drive (opcional)
- 💾 Exportar/Importar JSON
- 📱 PWA instalável — funciona offline

## Stack

HTML/CSS/JS puro. Sem build, sem dependências. Pode rodar direto no GitHub Pages.

## Como rodar localmente

Basta abrir `index.html` num navegador. Para PWA completo (instalação + offline), precisa servir via HTTP — qualquer servidor estático funciona, ou use o próprio GitHub Pages.

## Deploy

1. Faz push neste repo
2. Em Settings → Pages → Source = `main` branch, `/ (root)`
3. URL fica disponível em `https://SEU_USUARIO.github.io/SEU_REPO/`
